## Sobre o Projeto

O **Kerykeion** é uma aplicação web interativa de e-commerce desenvolvida como projeto escolar com temática baseada na **mitologia grega**. A loja simula um mercado itinerante gerido por Hermes, onde mortais e divindades podem encontrar artefatos, relíquias, armas e acessórios místicos.

O projeto foi desenvolvido para praticar manipulação do DOM em JavaScript com arrays, estilização com CSS moderno e dinâmico, e estruturação HTML semântica.

---

## Funcionalidades

* **Modo Escuro / Claro (Tema Artemis):** Alternância dinâmica de tema simulando a transição entre o dia e a noite no Olimpo.
* **Busca em Tempo Real:** Filtro instantâneo dos artefatos por nome, descrição ou categoria.
* **Filtro por Categorias:** Navegação fácil por seções (Artefatos, Relíquias, Armas, Defesa, Acessórios).
* **Item do Dia:** Sistema automatizado que destaca um artefato diferente a cada dia.
* **Bênçãos do Olimpo:** Mensagens dinâmicas e rotativas dos deuses ao carregar a página.

---

## Tecnologias Utilizadas

* **HTML5** — Estrutura semântica.
* **CSS3** — Variáveis CSS (Themes), Flexbox e estilização personalizada.
* **JavaScript (Vanilla)** — Lógica da aplicação, filtros e manipulação do DOM.
