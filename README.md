## Sobre o Projeto

O **Kerykeion** é uma aplicação web interativa de e-commerce com uma temática baseada na **mitologia grega**. A loja simula um mercado itinerante gerido por Hermes, onde mortais e divindades podem encontrar artefatos, relíquias, armas e acessórios místicos.

O projeto foi desenvolvido com foco em manipulação avançada do DOM, estilização dinâmica e uma experiência imersiva para o usuário.

---

## Funcionalidades

* **Modo Escuro / Claro (Tema Artemis X Apolo):** Alternância dinâmica de tema simulando a transição entre o dia e a noite no Olimpo.
* **Busca em Tempo Real:** Filtre instantaneamente os artefatos por nome, descrição ou categoria.
* **Filtro por Categorias:** Navegação por seções (Artefatos, Relíquias, Armas, Defesa, Acessórios).
* **Item do Dia:** Sistema automatizado que destaca um artefato diferente com base na data atual (gerador de seed diário).
* **Bênçãos do Olimpo:** Mensagens dinâmicas e rotativas simulando avisos dos deuses ao carregar a página.

---

## Tecnologias Utilizadas

* **HTML5 Semantic** — Estrutura da página.
* **CSS3** — Estilização personalizada, Flexbox e Variáveis CSS (Theming).
* **JavaScript (Vanilla)** — Lógica da aplicação, manipulação do DOM e interatividade.
